# عيادة د. سمر مجدي الاسكندراني — نسخة ثابتة (بدون بايثون)

تطبيق ويب كامل لإدارة عيادة الأسنان، شغّال بالكامل من متصفحك من غير أي
سيرفر أو بايثون أو قاعدة بيانات خارجية. كل البيانات بتتخزن جوه المتصفح
نفسه (localStorage).

## طريقة التشغيل

افتحي ملف `index.html` مباشرة في أي متصفح (كروم / إيدج / سفاري)، وهيشتغل
فورًا. تقدري كمان تحطي المجلد على أي استضافة استاتيك عادية (GitHub
Pages, Netlify, أو حتى فلاشة USB) لأنه مفيهوش أي كود سيرفر.

> ملحوظة: لأفضل تجربة (خصوصًا لو المتصفح رفض تحميل ملفات JS من `file://`)،
> شغّلي أي سيرفر استاتيك بسيط بلغة تانية غير بايثون، زي:
> `npx serve .` (لو عندك Node.js) أو افتحي المجلد بإضافة "Live Server" في
> أي محرر أكواد.

## أول دخول

أول مرة هتفتح فيها التطبيق هيوجّهك لصفحة "إنشاء حساب" لأن مفيش يوزر
محفوظ لسه — اعملي اليوزر والباسورد بتاعتك من هناك.

## البيانات وين بتتخزن؟

كل حاجة (المرضى، الزيارات، الخدمات، الحساب) بتتخزن في `localStorage`
بتاع المتصفح على نفس الجهاز والمتصفح اللي بتفتحي بيه التطبيق. لو مسحتي
بيانات المتصفح أو غيرتي جهاز، البيانات مش هتكون موجودة إلا لو عندك نسخة
احتياطية.

## النسخ الاحتياطي والاستعادة

من صفحة "الإعدادات":
- **تحميل نسخة احتياطية**: بينزّل ملف `clinic_backup.json` فيه كل
  بيانات العيادة.
- **استعادة نسخة احتياطية**: ارفعي نفس ملف الـ JSON ده لاستعادة كل
  البيانات (هيستبدل أي بيانات موجودة حاليًا).

احتفظي بنسخة على فلاشة أو جوجل درايف بشكل دوري.

## هيكل الملفات

```
index.html        # هيكل الصفحة الرئيسي
css/style.css      # كل التصميم والحركات والزخارف
js/db.js           # طبقة البيانات (بديل قاعدة بيانات Flask/SQLAlchemy)
js/app.js          # الموجّه (Router) وكل صفحات التطبيق والتفاعلات
```

## ملاحظة أمان

كلمة السر بتتخزن كـ hash (SHA-256 مع salt) جوه المتصفح، لكن ده مش بديل
حقيقي لأمان سيرفر فعلي — التطبيق ده مناسب للاستخدام الشخصي/المحلي داخل
العيادة، مش لنشر بيانات مرضى حساسة على الإنترنت العام.
